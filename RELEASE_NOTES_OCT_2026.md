## Publish with GitHub Pages

Copy the **contents** of this `rifatht.github.io` folder into the root of the GitHub Pages repository `rifatht.github.io`, retaining `index.html` and `.nojekyll` at the root. Commit and push to the branch configured for deployment. Use GitHub Settings > Pages to check the deployment status.
