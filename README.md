# Rifat Hossain Talukder | Geospatial Research Portfolio

Static academic portfolio prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root. `index.html` should be at the root.
3. In **Settings > Pages**, deploy from the `main` branch and `/ (root)`.

No build step is required.
