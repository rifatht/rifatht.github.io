# Rifat Hossain Talukder: academic research website

Static HTML, CSS and JavaScript for GitHub Pages. There is no build step.

## Publish

1. Extract this package and copy the contents of the `rifatht.github.io` folder to the root of your GitHub repository named `rifatht.github.io`.
2. Commit the changes to your default branch. GitHub Pages must be configured to publish from that branch's root (or an equivalent configured workflow).
3. Check the live site after deployment, especially the thesis figures, CV download and portfolio PDF.

The website in this package has **not** been uploaded to GitHub or deployed.
